# ISSUE-037: No stated position on AI-assisted code provenance

**Status:** Open · **Severity:** Pre-sale · **Area:** Due diligence / Legal
**Location:** repo-wide (no policy document exists)
**Source:** Due-diligence readiness review, 2026-08-06.

## Problem
Acquirers now routinely ask what proportion of a codebase was produced with AI assistance, under
which tool and which terms of service, because it bears on the IP representations and warranties the
seller is asked to sign at closing.

There is no document in this repo stating a position. Answering the question extemporaneously during
diligence — or worse, inconsistently across sessions — is materially worse than having a short,
accurate, prepared statement.

This is a disclosure and documentation task, not a remediation task. The commercially useful
position is a factual one: which tools were used, that their terms assign output to the user, and
that no third-party proprietary code was incorporated.

## Fix
Write a short provenance statement covering tools used, the terms under which output is owned,
review practice applied to generated code, and confirmation that no code was copied from other
proprietary sources. One page. Keep it in the repo so its date and content are fixed rather than
reconstructed under pressure.
